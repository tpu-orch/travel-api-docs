# Travel API Documentation v1.0

Статический каталог документации OpenAPI и AsyncAPI для публикации на GitHub Pages. Бэкенд часть не требуется: документации хранятся в `docs/specs`, а браузер загружает и отображает их на странице `docs/index.html`.

## Как добавить документацию

1. Положите спецификацию OpenAPI в `docs/specs/openapi/`, AsyncAPI - в `docs/specs/asyncapi/`.
2. Добавьте одну запись в объект `documents` в `docs/app.js`: уникальный ключ, тип (`openapi` или `asyncapi`), заголовок и путь к файлу. Поле `label` задаёт подпись в меню.

Пункт меню и группа OpenAPI/AsyncAPI создаются автоматически из этого списка.

## Структура страницы

- `docs/index.html` - разметка страницы и подключение библиотек.
- `docs/styles.css` - стили страницы.
- `docs/app.js` - единый список спецификаций, автоматическое построение меню и логика отображения и ссылок.

## Ссылки на документ

Выбранный документ записывается в параметр `doc` адреса страницы. Например, `?doc=tickets-asyncapi` сразу открывает AsyncAPI документацию билетов. Кнопка `Скопировать ссылку` копирует адрес с текущим документом, чтобы он сразу же открылся при переходе по скопированной ссылке.

Документы опубликованы как статические файлы. Для отображения используются Swagger UI и официальный AsyncAPI React Component.

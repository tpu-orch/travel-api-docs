# Travel API Documentation v1.0

Статический каталог документации OpenAPI и AsyncAPI для публикации на GitHub Pages. Бэкенд часть не требуется: спецификации хранятся в `docs/specs`, а браузер загружает и отображает их на странице `docs/index.html`.

## Добавить документацию

1. Положите спецификацию OpenAPI в `docs/specs/openapi/`, AsyncAPI — в `docs/specs/asyncapi/`.
2. Добавьте документ в объект `documents` в `docs/index.html`, указав уникальный ключ, тип (`openapi` или `asyncapi`), заголовок и путь к файлу.
3. Для каждого документа добавьте `<option>` в соответствующую группу `<select id="api-select">`.

## Ссылки на документ

Выбранный документ записывается в параметр `doc` адреса страницы. Например, `?doc=tickets-asyncapi` сразу открывает AsyncAPI документацию билетов. Кнопка `Скопировать ссылку` копирует адрес с текущим документом, чтобы он сразу же открылся при переходе по скопированной ссылке.

Документы опубликованы как статические файлы. Для отображения используются Swagger UI и официальный AsyncAPI React Component через CDN.
